# 心间漫游 2.0 验证记录

日期：2026-11-01。验证对象为本次可移植静态工程；不是心理学专业同行评审或学习效果证明。

## 内容与漫画

- 24篇完整主题、8个展区，每篇6格，共144张独立大图。每格分别调用内置imagegen；没有以旧六格拼页裁切冒充独立生成。
- 每张原图1254×1254，图内中文气泡。全部逐格对照当前对白、说话者、关键物体、叙事顺序和科学含义检查，并完成第二轮视觉复查。
- 已修正会改变概念的图像细节，包括：回忆任务展示现成答案、性格刻度的价值高低暗示、概率与实际次数混淆、投票图数量、归因故事角色过早到场等。
- 人格/压力/注意/脑网络等艺术隐喻与真实机制区分；临床相关内容保留求助与支持边界，不输出诊断。
- 18个交叉分支目录中16个已有相关故事，进化与积极心理学明确注明尚无专课；不把目录覆盖等同于完整教学覆盖。
- 8个生活场景、11份研究导览、11张书籍卡、10组人物展签有真实关联；成人延伸阅读默认折叠。

- 数据、导航引用、图片路径、尺寸、144张图片唯一哈希及无活动视频的完整性验证。

## 云端浏览器实际检查

- 首页、故事索引、分支/场景/实验入口、知识地图与书籍人物展签。
- 分支筛选、无结果搜索、浏览器返回和重置；认知分支4课，重置恢复24课。
- 独立漫画图保持比例，首格优先加载、其余懒加载；图内对白、六格导航、放大、关闭与Esc返回。
- 400 CSS像素窄窗口下，首页、地图、场景、漫画、框架演示无横向溢出；实际漫画宽约338像素，气泡可辨读。
- 书签和已读刷新保持；取消清除保留，确认清除恢复零记录。测试仅使用新建测试记录。
- 框架演示精确100格：90存活、10未存活，切换措辞保持总数和两组数量不变。
- 12张颜色命名教学任务：中性/冲突材料各6张、三色平衡，实际完成包含匹配与不匹配的流程；再次开始和中途重置正常。自动化输入只检验功能，不是人的实验数据。

## 尚未验证或不能由本次检查证明的事项

- 真实儿童/青少年阅读偏好、迁移效果及长期学习收益。
- 外部心理学专家的正式同行评审。
- 实体手机、全部浏览器、完整屏幕阅读器与无障碍认证。
- 实际打印输出：打印调用与样式已提供，但本云端浏览器未显示可检验的打印预览，不能标为打印验收通过。
- 没有推送GitHub或部署公共网站；云端预览属于临时本地运行。
