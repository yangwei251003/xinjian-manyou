# 漫画学习设计：从好看到会用

本次迭代面向小学高年级至初中可读，同时保留成人继续深入的入口。这是设计假设，不是经过儿童用户测试得到的结论。

## 研究提醒

- Cohn（2020）综述指出，连续图像理解也需要经验与练习，不能假定漫画天然人人都懂。因此分镜明确编号、保持动作连续，必要时用短旁白说明时间和地点变化。来源：https://link.springer.com/article/10.3758/s13423-019-01670-1
- Kakimova 等（2026）对 137 名五年级学生的预注册随机研究，没有发现加入短叙事或三幅代表性图片带来理解和兴趣优势。这不是对所有漫画的否定，而是提醒不能只改包装。来源：https://link.springer.com/article/10.1007/s10212-026-01137-7
- Ricci 等（2024）比较小学三年级生物多样性图像叙事与幻灯片教学，漫画组科学态度更积极，传统组内容测验更好。吸引与掌握要分别检验，不能互相替代。来源：https://pubmed.ncbi.nlm.nih.gov/39587311/

## 在产品中的落实

1. 一个故事解决一个具体问题。人物遇到问题、作出猜测、看到新证据，再尝试不同动作。
2. 图像必须展示动作、线索、变化或机制；少用多人站着解释同一句结论。
3. 旁白、对白与画面各自提供信息，避免三份重复长文字。
4. 机制隐喻明确标注为比喻，不把心理学画成神奇开关或固定人格标签。
5. 读完在另一情境中判断如何运用，反馈解释原因，不能只奖励记住术语。
6. 故事阅读和深入原理分层，但证据边界不能藏到难以发现的位置。
7. 不排名、不公开学生记录、不收集个人心理状况。实验演示不提供诊断、人格分型或能力常模。

## 尚待真实用户验证

真实学生是否愿意继续读、能否复述因果关系、能否处理新的生活情境，均不能由开发者截图审美或自动化测试替代。后续可在监护人和学校适当同意的前提下进行少量自愿阅读观察，避免收集敏感心理信息；当前未开展此类研究。
