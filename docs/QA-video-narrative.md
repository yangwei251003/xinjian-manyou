# 叙事重制核验 · 2026-11-06

本轮纠正的是内容衔接。旧版把独立结论和建议放入固定镜头格，缺少连贯的问题与解释。新版本先写完整连续讲述，再用图形演示；不插入漫画图片，不把漫画对话当作视频脚本。

## 实际交付

- 14支新片覆盖28课，每片约135.2秒，1920×1080、60fps、8112帧。
- 总计336段双语讲述。最长中文阅读速度约5.05字/秒；按句长分配时长，再对齐实际音乐节拍。
- 保留用户原始AAC，未添加口播、替换音乐、变速或调整增益。新片在本地版28课页和独立14片目录可播。
- OpenFilm应用、数据目录与入口已移入回收站，后台进程已停止；320个共享素材已逐文件校验并移到独立素材库。本轮和后续工作流均不接入该工作台。

## 脚本逻辑与研究边界

14片分组、336段中英文经过独立审读，37条修订已读回核对，两项实质问题已修复。分组不靠主题名称硬拼，必须有共同问题。例如：

- 学习片区分5分钟再学习优势与2天/1周提取优势，再明确习惯、睡眠来自不同研究问题，生活计划并非原实验完整流程。
- 沟通片沿用同一个面板例子：先区分观察与归因，再检查信息差，再倾听与核对。按圆形失败、按三角等待黄灯的符号关系保持一致。
- 研究片使用同一虚构观察：连续几天、午后球场旁、按日期记录销量与树荫人数。散点每点是一日；天气只是虚线候选解释，重复相关不自动证明因果。
- 测量片把一致性与用途证据分开，再用脑图说明“观察到解释”的推断条件；无个人诊断或虚构量表结果。
- 感恩片把群体研究平均结果与可选练习分开，“困难与支持同页”不冒充原实验。

最终稿见[连续讲述稿](../production/narrative/连续讲述稿.md)，独立审读和修订记录见[工程review](../production/narrative/review/)。原研究与许可见逐片脚本、reference/usage.json和课程出处。审读不等于心理学专业人员背书。
