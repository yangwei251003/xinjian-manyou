# 3.0 素材、参考与资料

更新于2026-11-05。

## 原创部分

28支视频的脚本、英文翻译、Canvas主题机制图及配乐由本项目创作。每支使用独立主题图形与种子，画面状态由显式时间推导。音乐由production/score.py原创合成，音乐、动作音效与混音分轨保留。公开范围见CONTENT-LICENSE.md。

新课24张漫画通过内置imagegen逐格生成。知识诅咒第5格修订机器人与遥控器的一致性，确认偏误第4格修订三张卡数量。提示词和版本记录见production/comics.json。对白为可编辑网页叠层。

片中字幕是原创解说与翻译。片尾研究者姓名标记资料来源。用户提供AAC完整解码约135.19秒，作为私人节奏参考。公开成片采用原创76BPM器乐。
