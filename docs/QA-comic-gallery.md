# 漫画册页布局验收

核验日期：2026-11-05。范围：当前运行版的28个故事、168张漫画，以及使用共享故事卡的页面。

## 最终行为

- 桌面三列两行，手机两列三行；所有六格都在页面中连续展开，不需逐页翻看。画面按原比例完整显示。
- 册页中的漫画宽度上限约252像素。较小屏幕自适应缩放，细节通过放大阅读。四门带网页对白的课程在册页上保持至少12像素，放大后随画幅增大。
- 桌面将预测问题与故事提示放在册页旁，手机依次接续。短片使用收敛的画幅，机制说明保留合适的行宽与关联资料入口。
- 首页、故事列表、书架和相关推荐共享较小的完整图预览；手机使用图文并排卡片。
- 放大阅读支持前后按钮、左右方向键、首尾边界与 Esc 关闭。关闭后焦点回到原来点击的漫画格。

## 实际验证

- `npm run check`、`npm test`、`npm run validate`通过。25项原有测试、28课及10个发现／系统页的渲染检查通过。
- 使用独立、无头的本机Chrome；没有操作用户的前台窗口或浏览器资料。
- 1366、390像素宽分别走查全部28课；320、768、1024像素宽分别检查归因、感恩记录与信效度三课，合计65次布局检查。
- 每次均核对真实课程标识、全部六张图片加载、左右与上下阅读顺序、完整图片比例、对白边界、无横向溢出、资料入口，以及初次阅读不请求MP4。
- 桌面与手机分别验证放大按钮、方向键、首尾禁用状态、关闭后焦点恢复、图片与控制条完整容纳、六格文字稿及预测反馈。另检查首页、故事列表、书架、知识地图、发现大厅、书与人和关于页面的宽度。
- 原有视频回归在1366与390像素宽分别检查全部28课：显式播放、暂停、拖动到44秒、同步字幕、文字稿，以及播放失败后的重试。56次课程走查通过。
- 实际查看了桌面整册、手机对白、手机故事卡和重新排版的短片区域截图。这里只记录界面观测，不推断真实用户的学习效果。

逐项证据：[65次布局检查](comic-gallery-validation.json)、[56次视频与课程回归](browser-v3-gallery.json)。截图：[桌面册页](previews/comic-album.png)、[手机册页](previews/comic-album-mobile.png)。

复现布局测试：启动网站后运行下列命令，并指定本机已有的Playwright入口。

```sh
node tests/comic-gallery.mjs --base http://127.0.0.1:4173/ --playwright /path/to/playwright-core/index.mjs --out qa/comic-gallery.json
```
