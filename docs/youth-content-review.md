# 心间漫游 v2：内容改版说明

日期：2026-11-01。阅读设计假设为小学高年级到初中，保留成人可展开阅读的解释层。此假设尚未经过真实学生可用性或学习效果研究。

## 已完成

- 24 篇原成人生活漫画改为 144 格原创校园、家庭与朋友故事，保留课程 ID 和八组展区。
- 角色为虚构学生小满、阿澈、米粒；依恋故事改为照顾者支持与科学营探索，不对儿童贴固定类型标签。
- 每课都有预测题及逐选项解释、三步机制、对应隐喻边界、常见误读、生活练习、另一情境的迁移题、研究解释和出处。
- 18 个交叉学科入口、8 个生活场景入口、11 个研究/实验导览。尚无完整课程的分支明确标识，不以空卡片充数。
- 经典研究、纵向观察、模拟、机制示意分开标注。网页不是标准化量表，不评分心理健康、人格或智力，不收集儿童心理或家庭信息。
- 生图提示改为每格独立大图，并逐字使用对应台词生成中文气泡；不是整页生成后裁切。

## 本轮科学性修订

1. 相关课改为“冰淇淋销量”和“树荫休息人数”两变量，气温是候选共同原因。避免把温度既当结果又当第三变量。
2. 复现课明确：幸运笔故事中的个人再次做题不是正式重复研究；题目熟悉与难度未控制。
3. 依恋不再混用成人伴侣量表与儿童行为。一次想家不判断依恋类型，不预测命运。
4. 睡眠补充 CDC 分年龄建议，明确不做熬夜对照实验。持续睡眠问题向可靠成人及医疗人员求助。
5. 求助与同伴支持以可靠成人和合适服务为重要连接，不让儿童承担唯一照顾者角色，不承诺绝对保密，不擅自套用地域热线。
6. “换想法”不能合理化持续伤害；边界表达不保证别人立即满意；习惯没有人人通用的固定天数。
7. 迁移题不再只让用户在“永远、一定”等明显错误说法与道德正确选项之间选择，加入新情境、信息不足与可竞争解释。
