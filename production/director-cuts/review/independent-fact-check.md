# 新版 14 片独立事实复审

已读 `film-plan.mjs` 的 14 片中文脚本，对照关键主张的一手来源和 `review` 中的相关成片样帧。以下为样帧和文字中可定位的修正。连续画面、听感及更改后的成片需另行验看。

| 片名与镜头 | 已观察到的问题 | 建议修改 |
| --- | --- | --- |
| 《2、4、6，试个反例》`reveal-rule` | 黑板写“任意三个依次变大的数”，同一组却画了 3、5、9、12 四个数。原实验要求每次提交三个数。尾句把“与自己的猜想相容”说成一定会错过更能区分解释的测试。相容与区分能力取决于另一条规则怎么预测。 | 画面保留 3、5、9 三阶。第二句改为“如果两条规则都预言‘符合’，这组数就区分不了它们。” |
| 《同一声碰撞，两种回忆》`afterweek` | 样帧题头“一周后的另一项实验”易读成实验一和实验二相隔一周。原文是在实验二内部，受试者看影片并填写问卷一周后返回作答。字幕“听过”也与书面问卷不符。 | 题头改“实验二 · 一周后追问”。第二句改“片中没有碎玻璃。先前读到‘猛撞’的人，更常回答看见了。” `wording` 的实验一如需给出具体方向，可将第二句写成“回答‘猛撞’问句的人，估计的车速更高。” |
| 《一张票的两面》`two-choices` | 字幕写“两种有风险的方案”，画面却明确是一个确定结果与一个有风险的结果。 | 首句改“给同一属性换个说法，和在确定结果与概率结果之间选，是两件事。” |
| 《一张票的两面》`package` | 画面和字幕只说评价受到影响，遗漏“75% 瘦肉”标签得到更正面评价，观众只看到两个标签而不知道差异方向。品尝后影响减弱的方向正确。 | 第二句改“标成75%瘦肉时，评价更正面。品尝后，措辞的影响减弱。” |
| 《把书合上以后》`comparison` | 图上有 5 分钟、2 天、1 周三个测验间隔，标题“两种测验时间”容易造成计数矛盾。原文实验 1 的重读与初测在同一参与者的不同短文上比较。“重读组、回忆组”容易被理解为按练法分成两群人。 | 题头用“同一实验，即时与延迟测验”或“三种测验间隔”。结果可写“5分钟后，重读的文章记得更多。2天或1周后，练过回忆的文章记得更多。”保留现在的结果反转方向。 |
| 《给今天留两个位置》`experiment` | “改善了部分主观感受”容易读成同一个人记录前后的改变。原摘要说明的是与其他条件相比，一些福祉指标存在组间差异。画面上的感恩、烦恼、普通事件三类对应第一项实验的每周记录。“今天的烦恼”容易读成每天记录。 | 第二句改“与对照组相比，感恩记录组有些福祉指标更好。” 画面改“遇到的烦恼”。`optional` 的双页仍作为本片日常示范。 |

## 一手来源

- Wason 1960，方法及原规则明确规定每组为三个依次增大的数。两条假设可根据对同一个例子的不同预测来区分。对正向检验与确认偏误的区别见 Klayman 与 Ha。[Wason 原文](https://web.mit.edu/curhan/www/docs/Articles/biases/12_Quarterly_J_Experimental_Psychology_129_%28Wason%29.pdf)、[Klayman 与 Ha 原文](https://pages.ucsd.edu/~mckenzie/KlaymanHaPsychReview1987.pdf)
- Loftus 与 Palmer 1974，实验一比较提问动词与车速估计。实验二的首次提问为问卷，一周后询问原影片中不存在的碎玻璃，报告比例受先前措辞影响。[论文原文](https://gwern.net/doc/psychology/cognitive-bias/1974-loftus.pdf)
- Levin 与 Gaeth 1988 的原摘要给出正面标签评价更好及品尝后差异减弱。确定结果和概率结果的选择在经典风险框架中另有实验设置。[属性框架原研究](https://academic.oup.com/jcr/article-abstract/15/3/374/1793963)、[Tversky 与 Kahneman 原研究](https://doi.org/10.1126/science.7455683)
- Roediger 与 Karpicke 2006，实验一方法、图一及结果段给出三种测验间隔和同人不同短文的比较。5 分钟时重读更好，2 天与 1 周时提取条件更好。[论文原文](https://gwern.net/doc/psychology/spaced-repetition/2006-roediger.pdf)
- 《测得稳，真的测对了吗》`scan` 与 `inverse` 的关键表达和样帧保留了任务比较及从亮区倒推时的替代解释，符合 Poldrack 对反向推断证据的限制。[Poldrack 原文](https://personal.utdallas.edu/~otoole/GRAD_CGS/R11_poldrack.pdf)
- Emmons 与 McCullough 2003 原摘要分别描述了记录条件和组间福祉比较。第一项研究包括记录感恩、烦恼和普通事件。[原研究摘要](https://pubmed.ncbi.nlm.nih.gov/12585811/)
