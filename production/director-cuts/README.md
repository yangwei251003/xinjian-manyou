# 心间漫游 · 原创动画

14 支逐片制作的动画覆盖 28 个心理学知识点。影片采用中文字幕、原创合成音乐或场景音效，网站提供双语字幕与研究出处。每支时长由演示和阅读所需的时间决定，交付为 1920 × 1080、30 fps 的 H.264/AAC MP4。

## 画面设计

| 短片 | 画面里的主要动作 |
| --- | --- |
| 球场上的第七位 | 俯拍的两队传球与黄伞横穿，随后标出另一条路线 |
| 同一声碰撞，两种回忆 | 胶片上的车相撞，两张提问纸进入档案并剪接记忆 |
| 把书合上以后 | 纸页遮住三个词，翻开核对，再走过即时与延迟测验 |
| 心跳没有字幕 | 幕布打开，两束灯照亮不同处境，同一心跳被重新理解 |
| 把镜头拉远一点 | 一张得奖照片退到画廊，露出练习和同伴，再缩小比较范围 |
| 独立也有补给站 | 剪纸徒步者出发、返回照料者、再探索，河上逐块搭起桥 |
| 站到他那一边 | 同一滑块装置旋转，挡板遮住红标，再用共同参照完成操作 |
| 2、4、6，试个反例 | 黑板上两种规则接收不同的三元组，线段任务展示多数答案 |
| 一张票的两面 | 票从正面翻到背面，着墨范围变化，分母保持 100 |
| 已经投进去的币 | 像素代币锁进机箱，未来的路线和可退票在另一侧展开 |
| 测得稳，真的测对了吗 | 秤反复读数，换成跑道问题，脑图亮区分出多种可能任务 |
| 一辆冰淇淋车的调查 | 微缩校园缩到一个样本，日记数据进入坐标，换地点复测 |
| 把今天的时间摊开 | 海报推入，晚间时间带展开，剪刀分出实际能承诺的部分 |

片名、双语台词和时间码集中在 `film-plan.mjs`。`shots/` 按片维护画面。`drawing.mjs` 提供画线、填色、字体和时间插值等基础工具。画面与音频由各自的源文件直接生成。

## 参考与素材

- 对照 MotionGit 的现代编辑讲解目录与 2.7.18-alpha.9 页面，取短句、主体和证据分层的组织方法。该页面列明整套模版的配音、图片和数据准备要求。本项目的场景实现与绘图为独立编写。 [MotionGit 模板页](https://motiongit.com/@adunext/template-01-integrated) · [模板目录](https://github.com/motiontemplates/all)
- 对照 Nicky Case 的可探索讲解。先给观众一项具体任务，再改变一项条件，让结果先于术语出现。这里用于传球计数、规则反例与票面切换。 [原作与源码入口](https://ncase.me/ballot/)
- 本机模板库用于比较纸墨、数据与叙事风格。成片的原创矢量画面和合成声音随项目许可分发。字体来源、散列和 OFL 许可保存在 `assets/`，各课研究出处随分镜显示。

## 生成与核验

需要 Node.js 22+、支持 WebCodecs 的本机 Chromium、Playwright、FFmpeg、Python、NumPy 和 Pillow。可通过 `CHROME_PATH`、`PLAYWRIGHT_PATH` 和 `FFMPEG` 指定已安装工具。项目附有字体子集，改变文字后可用 `tools/prepare.py` 从原始 OFL 字体重建。

```sh
python tools/sound.py
node render.mjs --workers 2
python tools/review_media.py
python tools/assemble.py --site /path/to/xinjian-manyou
node tools/player-check.mjs
```

`tools/sound.py` 为各片合成不同的乐句与场景音，并按镜头动作安排起音。球场、工坊和数字谜题使用场景音。压缩音轨已解码检查。

`review/technical-checks.json` 对应 14 支实际 MP4 的完整解码、84 镜的时间采样和 3,275 对去字画面比较。相似度帮助发现候选，画面意义以实际观察为准。事实复审核对了碰撞措辞实验、提取练习、反例、框架、脑图和感恩任务。浏览器检查包含 28 课在两种屏宽下的播放、拖动、字幕与失败回退。连续人工看听另待验证。
