# 14 支逻辑重制影片分组审读

2026-11-06。复用 routeId `eb338c0f-ae4d-4ae1-92df-5719dfdf7c4a`。

审读对象为本目录《任务简报》、`groups.json`、`lessons.json` 的 28 课观点、解释、边界和出处。原候选 14 组恰好覆盖 28 个不同课程 ID，没有遗漏或重复。本报告包含主 Agent 已采纳的两项主题迁移。groups.json 和连续脚本由主 Agent 更新。

本次只审分组、论证与证据。没有制作或审看成片，没有验证字幕阅读速度、实际卡点、全程音画一致或读者学习效果。原 AAC、无口播、漫画与视频独立创作作为既定条件。OpenFilm 的永久禁用优先于旧技能中要求使用该工作台的条款。

## 必须先修的逻辑

1. **注意与脑图原组合缺少回答同一问题的桥。** 不注意盲视研究能说明任务条件下对意外目标的报告差异，Poldrack 的反向推断讨论不能直接解释这种遗漏的神经机制。已采纳的调整是 attention 独立，brain 并入 test-validity。脑图组的共同问题是测得信号怎样支持心理解释。
2. **测量与抽样原组合混合了两级推断。** 一个测量对个人的解释依据，与一组样本能否代表目标人群，需要分别论证。已采纳的调整是 sampling 并入 correlation、replication，以一项虚构校园调查连贯检查对象、关联、候选原因及复核。
3. **支持组必须在叙事中完成换证据的过渡。** 依恋的安全基地研究与青少年求助/同伴支持建议有关联，但后者不能由婴幼儿分离观察直接推出。建议写成“这类研究关心支持与探索的关系。到了青少年遇到困扰的情境，怎样求助还需要另一类指导。”随后明确切换到 NIMH、UNICEF 的实践资料。
4. **多主题影片应围绕一个案例的下一步展开。** 习惯、提取、睡眠各作用于不同问题，重评、压力调整也不是同一机制。每次切换先说上一段仍未解决什么，下一段才有出现的理由。避免先列三项知识，再以共同口号收尾。
5. **研究、虚构演示、生活建议须各自归位。** 原始实验可以回答其设定的问题。动画中的案例是解释工具。生活动作是基于研究与实践资料提出的尝试。不能让三个层次共用一条“研究证明”字幕。

## 14 组最终建议

下表按原候选顺序列出，括号内为调整后的课程范围。问题是叙事约束，建议成片结尾能用一句完整回答收束。

| 组与课程 | 应贯穿的逻辑 | 必要修正与画面约束 |
| --- | --- | --- |
| 注意（attention）。“为什么眼前的信息，也会被漏掉？” | 有限时间中的明确任务 → 哪些信息得到优先处理 → 意外目标可能未被报告 → 改任务后看到的内容改变。 | 任务搜索与不注意盲视分开介绍。观众提前知道异常物体后再观看已有预期，不能作为第一次条件的复现。聚光灯只作比喻。若加 Stroop，须说明词义干扰是另一个范式，135 秒内宜集中讲意外遗漏。 |
| 记忆校准（memory、metacognition）。“记得清楚，为什么还要核对？” | 回忆的内容会受线索与后来信息影响 → 主观确信不足以单独确认细节 → 把确信变成可检查的预测 → 核对后更新。 | 先讲事件回忆，再说明元认知是检查自身判断的视角，不能把纸飞机学习校准研究直接当目击回忆的干预证据。不要暗示自信通常无用，也不要把细节错误等同于整段经历虚假。 |
| 学习循环（retrieval、habits、sleep）。“怎样从看过，走到能想起？” | 反复看为什么熟悉 → 合上材料提取能暴露缺口 → 怎样让这个动作容易在下一次发生 → 还要给学习与睡眠留出条件。 | 原始提取实验在 5 分钟即时测验与 2 天/1 周延迟测验有不同方向，曲线的时间轴必须明确。习惯只回答动作能否重复启动，睡眠是学习/保持的相关条件，三者不能画成已被同一实验验证的必然流水线。 |
| 情绪与处境（emotions、stress、reappraisal）。“同样心跳快，为什么感受不同？” | 一个身体信号可出现在不同情境 → 感受还涉及目标与解释 → 检查哪些压力来自现实负荷 → 能改变的条件采取行动，解释过满处再尝试重评。 | 跑步、惊喜与上台的示意不能伪装成完全相同的生理测量。不能把“所有压力来自想法”作为结论。Troy 的情境可控制性结果及勘误是条件性证据，不支持所有人都能按控制程度得到同样收益。 |
| 比较与特质（comparison、personality）。“别人的高光，能给你定性吗？” | 选择性展示造成比较材料不完整 → 单次/单维度差异不能推出整个人 → 人格描述跨情境倾向，具体行为仍有变化 → 收窄比较到可观察动作。 | 不要把向上比较统一画成伤害。人格连续维度示意不能变成某个真实人的测验分数。不得用一次发言推断外向性，也不能以情境变化否定特质的相对稳定。 |
| 支持与探索（attachment、support、help-seeking）。“需要帮助，会让人更不独立吗？” | 从支持与探索能并存的概念开场 → 发展阶段改变，求助的方式与职责也改变 → 同伴可倾听/陪同连接资源 → 更大困扰联系可靠成人及合适专业服务。 | 依恋理论和青少年支持指南显式换证据。避免陌生情境类型图直接变成青少年的固定类型。安全基地是关系功能，不是“一个人必须永远在线”。不承诺有支持就会独立或症状改善。 |
| 沟通信息差（attribution、knowledge-curse、listening）。“沟通卡住时，我们究竟漏了什么？” | 我看到一个行为却不知道其情境 → 我讲了一句话却省略了自己已有的知识 → 即使解释完事实，也需知道对方此刻想讨论什么 → 用询问和复述补齐三种信息。 | 同一个非漫画案例贯穿，避免三个新故事各讲 30 秒。归因、信息不对称与被理解感是不同研究问题。倾听是核对需要的动作，不能说它“消除了知识诅咒”。Newton 数字口径不一，使用“预估远高于识别结果”即可。 |
| 共识与证据（conformity、confirmation-bias）。“大家都同意，就足够证明了吗？” | 多数意见可以带来信息或合群压力 → 意见一致仍需看如何形成 → 检查例子是否真能区分竞争解释 → 允许不同判断接受同样检验。 | 从众与确认偏误可能同时出现，不能画成固定因果链。相互转述同一个说法不构成多份独立证据。正向测试有时是有效策略，重点是测试的信息量。少数意见也需提供证据。 |
| 表述与选择（framing）。“九成得到和一成没得到，差在哪里？” | 同一人群、时间、规则、成本及二元结果 → 两种互补表达 → 关注重点/评价可能改变 → 还原成相同条件再判断。 | 这支围绕属性框架展开。经典确定性/概率选项的风险框架可以在出处提及，不能把其数据直接贴在九成/一成动画上。分母、成功定义、第三种结果有变时先停止声称等价。 |
| 未来成本（sunk-cost）。“已经花了这么多，就必须继续吗？” | 过去不可追回的投入 → 现在仍可改变的收益成本 → 区分可用技能/部件、退费、承诺、收尾价值 → 给继续或停止写面向未来的理由。 | 已有投入与完成进度不能随意混成一个操纵。不要让所有“继续”都变成错误答案，也不要让停止一定获得更高收益。画面中的两条未来路径应保留各自代价，避免对心理学做道德裁决。 |
| 信号与解释（test-validity、brain）。“一张脑图、一个分数，凭什么解释你？” | 先得到一项记录 → 检查其精确/稳定程度 → 记录与拟议解释、用途需要证据连接 → 脑区活动也是信号，需要比较、选择性与预测验证。 | 不把效度概括成仪器“准不准”。要问的是分数解释及用途。脑图部分自然接“测到了，不等于解释完成”，同时承认规范方法能提供预测信息。点亮脑区示意不能冒充实测影像，连续人格刻度也不是量表结果。 |
| 研究与结论（sampling、correlation、replication）。“一个研究结果，凭什么值得相信？” | 同一虚构校园调查先确认问了谁 → 看两项记录的共同变化 → 给出可竞争的原因 → 换样本/条件进行新的检查 → 按设计能力写结论。 | 全片保留同一研究问题和变量，避免从活动偏好突然跳到冰淇淋。再次得到关联只能增加对关联的信心，不能消除共同偏差或自动证实因果。随机抽样与随机分配的两种用途须分开。统计复核、重分析与新数据重复研究不能用同一个循环箭头替代。 |
| 清楚的限度（boundaries）。“想帮忙，怎样把限度说清楚？” | 识别当前能力/时间 → 清楚表达可以承担什么 → 由自己执行的可行动限度 → 对方反应与下一步。 | 不以对方马上开心作为成功证据。拒绝可以没有替代服务。只说“你不能生气”是约束他人感受，和说明自己的行动有别。权力不等或存在威胁的案例，不套用普通合作台词。 |
| 两种经历并存（gratitude）。“困难还在，也能看见一点支持吗？” | 真实困难先成立 → 同时发现一次具体帮助 → 说明研究比较过何种记录 → 把它作为有选择的观察，仍处理困难。 | 2003 年研究是多项实验，不宜合并成一条通用提升百分比。原摘要只支持若干、而非全部指标的组间差异。青少年日常使用不能直接当作同样有效的实测结论。“同时记录困难与支持”是本片教育设计，不是原实验已经验证的组合方案。 |

## 脚本阶段的连续逻辑验收

- 读完整篇后，应能用同一主语和同一问题复述论证。每次换知识点，前后应有一个明确尚未解决的问题，转场句回答“为什么这段需要接在这里”。
- 出现“因此、所以、这证明、导致、只要”时，检查前一条证据是否真的支持该强度。只具有关联的结果使用相称表述，生活建议说明根据与可试条件。
- 每个数字确认对象、任务、条件、时间与分母。相邻画面不得在无说明时更换这些要素。虚构示意不给研究结果式的小数、显著性星号或真实作者标签。
- 中文与英文对同一事实、条件和否定保持一致。图示先完成所需的信息动作，字幕才给推断，避免字幕已经否定的东西仍在画面里被画成确定因果。
- 24 段是承载连续讲述的容器。关系紧密的两段可以共用一个正在变化的图示，段落切换不必重置场景。先确认连续讲述能成立，再拆时序。
- 边界应出现在可能误解的推断旁。结尾保留对主问题的一句回答，避免全片末尾连列通用警告把论证冲淡。

## 已核对的一手或官方依据

本次核对的是与关键桥梁直接相关的公开正文或摘要。没有逐篇重新通读所有课程论文。

- Poldrack（2006）讨论从活动推心理过程所需的选择性与额外信息。2011 年文章继续讨论可正式检验的预测/解码方法。因此既要阻止“脑区一亮就读懂心理”，也要避免说脑成像完全无法提供心理信息。本次 PMC 全文遇到验证码，已核对 PubMed 摘要及图注。[2006 原文摘要](https://pubmed.ncbi.nlm.nih.gov/16406760/)、[2011 原文摘要](https://pubmed.ncbi.nlm.nih.gov/22153367/)
- AERA、APA、NCME《Standards for Educational and Psychological Testing》2014 开放原版，第 1 章印刷页 11、PDF 第 21 页说明效度针对分数解释与拟议用途，第 2 章说明信度/精确性须与用途、人群及误差条件相符。[专业标准原文](https://www.testingstandards.net/uploads/7/6/6/4/76643089/standards_2014edition.pdf)
- Roediger、Karpicke（2006）原始摘要明确区分 5 分钟、2 天和 1 周的测验。实验中的即时提取无反馈，不能把本片后续核对步骤当作同一实验程序。[原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/16507066/)
- NIMH 的儿童青少年资料提出向家长、学校支持人员及医疗人员求助。UNICEF 的 I Support My Friends 明确把同伴支持放在可信任成人指导与儿童保护条件下。它们能支持本片的实践层，不需要借用婴幼儿依恋分类为其背书。[NIMH](https://www.nimh.nih.gov/health/topics/child-and-adolescent-mental-health)、[UNICEF](https://www.unicef.org/serbia/en/documents/i-support-my-friends)
- Emmons、McCullough（2003）原始摘要列出三项实验和不同记录条件，并说明多个但非全部指标的差异。本文没有据摘要推断未展示的具体效应量、青少年效果或治疗作用。[原始研究摘要](https://pubmed.ncbi.nlm.nih.gov/12585811/)
- Wason（1960）与 Klayman、Ha（1987）支持把规则任务讲成对竞争解释的信息检查，后者也提醒正向测试在某些环境下有合理性。这是当前课程已有并在前一轮审读读过的原始材料，本轮没有重复下载。[Wason](https://doi.org/10.1080/17470216008416717)、[Klayman 与 Ha 原文](https://pages.ucsd.edu/~mckenzie/KlaymanHaPsychReview1987.pdf)
- 属性框架采用 Levin、Gaeth（1988），与 Tversky、Kahneman（1981）的风险选项框架分开。这是当前课程已有并在前一轮审读核过的原始资料。[属性框架原研究](https://doi.org/10.1086/209174)、[风险框架原研究](https://doi.org/10.1126/science.7455683)
